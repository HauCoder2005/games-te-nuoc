# TÉ NƯỚC! Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
> **Codex:** nếu không có các skill trên, làm **tuần tự từng task**, đúng thứ tự các bước (viết test → chạy thấy fail → code → chạy thấy pass → commit). Đánh dấu `- [x]` khi xong mỗi bước.

**Goal:** Game web nhiều người "TÉ NƯỚC!": 2 đội ném bóng nước đẩy nhau khỏi bè, đua tới 10 điểm, có server riêng với phòng riêng (mã 4 chữ) và ghép ngẫu nhiên.

**Architecture:** Monorepo npm workspaces. `packages/shared` chứa toàn bộ luật game thuần TypeScript, xác định theo seed, chạy được ở cả server lẫn client. `apps/server` là Colyseus 0.18 chạy luật (server quyết định mọi thứ), một loại phòng `match` cho cả chế độ `public` và `private`. `apps/client` là Vite + Canvas 2D, đồng bộ qua Colyseus Schema, có chế độ chơi offline với bot.

**Tech Stack:** Node LTS, TypeScript strict, npm workspaces, Vitest, Colyseus 0.18 (`colyseus`, `@colyseus/schema` 5, SDK client 0.18), Vite, Canvas 2D, `@fontsource/vt323`, ZzFX, Docker, Caddy, AWS S3 + CloudFront, máy ảo AWS Singapore.

**Spec:** `docs/design.md` (đọc toàn bộ trước khi bắt đầu; mockup `docs/mockup.png`, đồng phục `docs/nhan-vat.png`).

## Global Constraints

- Mọi hằng số gameplay/mạng nằm trong `packages/shared/src/config.ts` với đúng tên và giá trị ở mục 5 của spec; không viết số "ma" ở nơi khác.
- `packages/shared/src/sim/**` không dùng DOM, mạng, `Date`, `Math.random`; chỉ dùng `mulberry32(seed)`.
- Tick mô phỏng 30Hz (`DT = 1/30`). Thế giới 640×360, tâm bè (320, 199), bè đầu 32×14 ô, ô 16px.
- Tối đa 10 người/phòng, 2 đội `0 = Đỏ #E53B3B`, `1 = Xanh #3B8BF0`.
- Bảng chữ mã phòng: `ABCDEFGHJKLMNPQRSTUVWXYZ`, độ dài 4.
- `PROTOCOL_VERSION = 3`, gửi trong options lúc join.
- Tên người chơi: tối đa 12 ký tự, hiển thị chỉ bằng `textContent` hoặc canvas, không bao giờ qua `innerHTML`.
- Chữ trên giao diện là tiếng Việt, dùng đúng các câu thông báo ở spec mục 6.4.
- Colyseus: **đọc docs của đúng phiên bản 0.18 đã cài** trước khi viết code server/SDK. Tên API trong plan này là ý đồ; nếu API thực tế khác tên, dùng API tương đương của 0.18 và giữ nguyên hành vi.
- Asset có sẵn trong `apps/client/public/assets/` (kèm `manifest.json`); không vẽ lại.

**Files:**

**Interfaces:**
- Consumes: `activeCovers`, config.
- Produces:
  - (`hit.ts`) `applyHit(target: PlayerState, kind: 'direct' | 'splash' | 'dash', dirX: number, dirY: number, by: number, time: number): number` — bỏ qua (trả 0) nếu `protected|falling|respawning`; cộng `wet` trước rồi `lực = KB_x × (1 + wet / WET_SCALE)`; cộng vào `kb` theo hướng đã chuẩn hóa; `status='hitstun'`, `timer=HITSTUN`; ghi `lastHitBy`, `lastHitTime`; trả về lực
  - `applyMoveInput(p: PlayerState, inp: InputFrame, dt: number): void` — `v += (đích − v) × min(1, MOVE_ACCEL×dt)`, đích = hướng chuẩn hóa × `MOVE_SPEED` × (`HITSTUN_CONTROL` nếu `hitstun`), không đi khi `falling|respawning`
  - `integrate(p: PlayerState, dt: number): void` — vị trí += (mv + kb)×dt; `kb *= exp(−KB_DECAY×dt)`
  - `startDash(p: PlayerState, inp: InputFrame): boolean` — hướng phím, không có thì hướng ngắm; chặn khi đang `hitstun`, hồi chiêu
  - `resolveOverlaps(players: PlayerState[], time: number, events: GameEvent[]): void` — tách đều; nếu một bên đang `dashing` và bên kia là địch (không `protected`) thì `applyHit(..., 'dash', ...)` theo hướng húc, đẩy event `hit`, kết thúc cú húc; đồng đội thì chỉ dừng
  - `resolveCovers(p: PlayerState, covers): void` — đẩy ra khỏi hình vuông 16×16, triệt tiêu thành phần `kb` hướng vào thùng
